✅ 5. Boas práticas para banco local em produção
Prática	Descrição
Transações	Use transações (db.transaction(...)) ao realizar múltiplas inserções ou atualizações.
Tratamento de erro	Envolva as chamadas de banco com try/catch e envie mensagens claras para o frontend via ipcMain.handle.
Backups	Implemente uma opção de backup manual do .db, exportando para uma pasta acessível ou salvando em .zip.
Migrações	Crie scripts simples de migração de schema, por exemplo com PRAGMA user_version para detectar e atualizar versão do schema.
Conexão única	Instancie o Database uma única vez no processo main, evite múltiplas conexões simultâneas.
Sincronismo	Por padrão, o better-sqlite3 é síncrono, o que simplifica o controle, mas evite travar o main com chamadas longas demais. Use ipcMain.handle com feedback no UI se necessário.

// src/db/database.ts
import Database from 'better-sqlite3';
import fs from 'fs';
import path from 'path';

let dbInstance: Database.Database | null = null;

export function initializeDatabase(dbPath: string) {
  if (!fs.existsSync(path.dirname(dbPath))) {
    fs.mkdirSync(path.dirname(dbPath), { recursive: true });
  }

  const db = new Database(dbPath);
  db.pragma('journal_mode = WAL'); // mais seguro para concorrência

  // Criação da tabela de pacientes
  const createTable = `
    CREATE TABLE IF NOT EXISTS pacientes (
      id INTEGER PRIMARY KEY AUTOINCREMENT,
      nome_completo TEXT NOT NULL,
      data_nascimento TEXT,
      sexo TEXT,
      cpf TEXT NOT NULL,
      telefone TEXT NOT NULL,
      email TEXT,
      endereco TEXT,
      profissao TEXT,
      estado_civil TEXT,
      observacoes TEXT
    )
  `;
  db.prepare(createTable).run();

  dbInstance = db;
  return db;
}

export function getDb(): Database.Database {
  if (!dbInstance) {
    throw new Error("Banco de dados não inicializado!");
  }
  return dbInstance;
}

import { getDb } from './database';
import { Paciente } from '../types/Paciente';

export function criarPaciente(paciente: Paciente) {
  const db = getDb();
  const stmt = db.prepare(`
    INSERT INTO pacientes (
      nome_completo, data_nascimento, sexo, cpf, telefone,
      email, endereco, profissao, estado_civil, observacoes
    ) VALUES (?, ?, ?, ?, ?, ?, ?, ?, ?, ?)
  `);
  const info = stmt.run(
    paciente.nome_completo,
    paciente.data_nascimento,
    paciente.sexo,
    paciente.cpf,
    paciente.telefone,
    paciente.email,
    paciente.endereco,
    paciente.profissao,
    paciente.estado_civil,
    paciente.observacoes
  );
  return info.lastInsertRowid;
}

export function listarPacientes() {
  const db = getDb();
  const stmt = db.prepare('SELECT * FROM pacientes ORDER BY nome_completo ASC');
  return stmt.all();
}

🧠 Diagnóstico do problema:
Você está clicando em um dia/hora do calendário para criar uma nova sessão, e isso te leva para novaSessao.tsx, mas com o horário adiantado em 3 horas.

📌 Exemplo real:

Clicou em 08:00 → formulário mostra 11:00

✅ Causa mais provável:
O horário está sendo criado ou interpretado em UTC, e seu sistema local (ou navegador) está com timezone -3 (Brasília).

Isso é clássico com new Date() ou toISOString(), que convertem para UTC automaticamente.

✅ Solução orientada
Você precisa:

1. Ao clicar no grid, enviar o horário corretamente (sem conversão implícita):
No index.tsx do calendário, quando chamar router.push ou navigate, use:

const dataHoraSelecionada = new Date(ano, mes, dia, horaSelecionada, 0, 0);

// EVITE usar .toISOString()
router.push(`/agenda/nova?data=${dataHoraSelecionada.toISOString()}`);
👉 Problema: .toISOString() gera string em UTC
✅ Correto: use .toLocaleString() ou serialize manualmente

2. Ou envie o timestamp com new Date().getTime():
router.push(`/agenda/nova?timestamp=${dataHoraSelecionada.getTime()}`);
No novaSessao.tsx, você pode recuperar e converter:

const searchParams = new URLSearchParams(location.search);
const timestamp = Number(searchParams.get('timestamp'));
const dataHora = new Date(timestamp); // já no horário local
✅ Recomendação final
Use timestamp numérico (getTime()) para transporte entre rotas. É o método mais seguro, sem interferência de fuso.
