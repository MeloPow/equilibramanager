  • 2. Entidades e Banco de Dados
    • Paciente
      • Tabela criada em db/paciente.ts
      • Interface em types/Paciente.ts
      • Serviço em services/pacienteService.ts
    • Sessão
      • Relacionada ao paciente (chave estrangeira paciente_id)
      • Criada em db/sessao.ts
      • Interface em types/Sessao.ts
      • Serviço em services/sessaoService.ts
  • 3. Comunicação Preload <-> Renderer
    • preload.ts usa contextBridge para expor métodos em window.api
    • backend (main/index.ts) registra handlers com ipcMain.handle
    • renderer (React) acessa métodos via window.api
  • 4. Funcionalidades do App
    • ✅ Adição e listagem de pacientes
    • ✅ Criação e exibição de sessões na grade
    • ✅ Cards de sessão com cores dinâmicas por status
    • ✅ Calendário com controle de semanas e datas
    • ✅ Sistema visual belíssimo com MUI e imagens
    • ✅ Tipagem TypeScript em todo fluxo
  • 5. Tecnologias e Bibliotecas
    • Electron Forge + React + TypeScript
    • Material UI (MUI) para design e responsividade
    • Better-sqlite3 como banco de dados local
    • date-fns para manipulação de datas
    • Preload com contextBridge para segurança
